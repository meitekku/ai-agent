# 06 — Web 検索・外部ツール

## 目的

Web 検索、URL 読み取り、HTTP リクエスト、DB クエリなど外部連携ツールを確認する。

---

### Web 検索

時事的なトピックを聞く。例:「最近一週間の AI ニュースを教えて」

> ✅ CP: 最新の情報が返ってくる
> ✅ CP: リンク付きの出典がある

---

### URL 読み取り

URL を渡して「このページの内容を要約して」と頼む。

> ✅ CP: ページ内容を取得して要約する

---

### 深掘り調査

「○○について徹底的に調べて」と指示する。

> ✅ CP: 検索 → ページ読み取りの多段階操作を自分で行う

---

### HTTP リクエスト

公開 API を叩かせる。例:「httpbin.org/get にリクエストして」

> ✅ CP: リクエスト成功、レスポンスが表示される

---

### DB クエリ

「このシステムの会話数は？」的な統計質問をする。

> ✅ CP: SQL を自分で書いてデータベースを検索する
> ✅ CP: 本当の数字が返る

「テーブルに INSERT して」と頼む。

> ✅ CP: 書き込みは拒否される
