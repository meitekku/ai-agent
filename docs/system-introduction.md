## 製品コンセプト

SalesNavi AI は、社内ナレッジと Salesforce の顧客データを AI が自動的に統合し、営業活動をリアルタイムで支援するプラットフォームです。

「調べる → 理解する → 資料を作る → 提案する」という営業の日常業務を、AI が一気通貫でサポートします。

---

## 解決する課題

| 営業の悩み | SalesNavi AI の解決策 |
|---|---|
| 社内資料が散在し、必要な情報が見つからない | AI が全社ドキュメントを横断検索し、即座に回答 |
| 顧客情報を Salesforce で調べてから資料に反映するのが手間 | Salesforce データを AI が自動取得、商談に最適な情報を提示 |
| 提案書やプレゼン資料の作成に時間がかかる | 会話から AI がスライドを自動生成、スタイル・業界に合わせてカスタマイズ |
| ナレッジが属人化し、組織で共有されない | ナレッジベースに蓄積 → 誰でも AI 経由で活用可能 |
| 新人営業の立ち上がりが遅い | AI が社内ノウハウを元にベテラン同等の回答を提供 |

### 技術スタック

| レイヤー | 技術 | 選定理由 |
|---|---|---|
| フロントエンド | Next.js + TypeScript + Tailwind CSS | 高速開発、SSR 対応、モダン UI |
| AI/LLM | 任意の LLM（API 接続） | マルチモーダル対応、プロバイダー差替え可能 |
| RAG エンジン | LightRAG + Knowledge Graph | 従来の RAG を超える関係性理解、高精度な回答 |
| ベクトル DB | PostgreSQL + pgvector | 運用コスト低、既存 DB と統合可能 |
| コンテナ | Docker Compose | ワンコマンドデプロイ、環境差異なし |

### デプロイ要件

- **GPU 不要** — CPU のみで動作（LLM はクラウド API を使用）
- **必要な設定は API Key 1つだけ** — LLM の API Key を設定するだけで即稼働
- **リソース消費**: 全コンテナ合計 約 410 MB（軽量）

## 主要機能

### 1. AI ナレッジベース検索（RAG）

社内ドキュメントを AI が読み解き、**ナレッジグラフ**（知識の関係性マップ）として構築。単純なキーワード検索ではなく、文脈と関係性を理解した高精度な回答を生成します。

**特長:**
- **マルチナレッジベース**: 部門・プロジェクト・顧客別に複数の KB を作成・管理
- **自動知識構造化**: アップロードされた PDF・テキストから、エンティティ（人物、企業、製品等）と関係性を自動抽出
- **ハイブリッド検索**: ベクトル検索（意味の類似性）+ グラフ検索（関係性の探索）を組み合わせた高精度検索
- **OCR 対応**: スキャン PDF や画像内のテキストも AI OCR で自動認識・取込
- **マルチモーダル**: 画像・PDF・テキストファイルをチャットに直接添付して質問可能

**利用シーン:**
- 「A 社との過去の取引履歴と、担当者の反応は？」
- 「競合 B 社の製品と比べた我が社の優位性を教えて」
- 「この業界の最新トレンドを社内資料から整理して」

### 2. Salesforce 連携（Sales Cloud Integration）

Salesforce Sales Cloud の顧客データを AI が**バックグラウンドで自動同期**。営業担当が Salesforce を開かなくても、チャットで顧客情報にアクセスできます。

**特長:**
- **自動データ同期**: 商談、リード、取引先、活動履歴を定期的に取得し KB に反映
- **自然言語クエリ**: 「今月クロージング予定の商談一覧」「A 社の直近の活動履歴」など自然な質問で情報取得
- **クロスデータ分析**: Salesforce のデータと社内ドキュメントを横断した AI 回答
- **商談準備の自動化**: 訪問前に顧客の最新状況・過去のやり取り・関連資料を AI が自動で要約

**利用シーン:**
- 「明日の A 社訪問に向けて、直近の商談状況と提案すべき内容をまとめて」
- 「今四半期の受注確度 B 以上の商談リストと、それぞれの課題は？」
- 「この顧客に類似した過去の成功事例を社内資料から探して」

### 3. AI スライド自動生成

チャットの回答内容から、そのまま提案資料やプレゼンテーションを AI が自動生成。業界・対象者に合わせたスタイルカスタマイズにも対応。

**特長:**
- **会話からワンクリック生成**: 「この内容でスライドにして」と指示するだけ
- **セットアップウィザード**: 産業・対象者・配色・枚数を選ぶだけで最適なスライドを生成
- **PPTX / PDF エクスポート**: PowerPoint や PDF にそのまま書き出し、すぐに商談で使用可能
- **スタイル自動推定**: コンテンツの内容から業界・職種を AI が判定し、最適な配色・レイアウトを提案

**利用シーン:**
- 「A 社向けの提案書を 10 枚で作って、金融業界向けのブルー配色で」
- 「さっきの回答をそのままスライドにして」
- 「KB の情報を使って、新製品の社内説明資料を作って」

### 4. スキルシステム（カスタム AI 指示）

営業チーム独自のノウハウや回答ルールを「スキル」として AI に教え込むことが可能。組織のベストプラクティスを AI に反映させます。

**特長:**
- **スキル CRUD**: 管理画面からスキルを作成・編集・有効/無効切替
- **ZIP アップロード**: SKILL.md + 参照ファイルをまとめてアップロード
- **動的注入**: 有効なスキルが AI のシステムプロンプトにリアルタイムで反映
- **チーム共有**: 作成したスキルは全メンバーが即座に利用可能

**利用シーン:**
- 「競合比較の質問には、必ず弊社の〇〇の優位性を含めて回答する」スキルを追加
- 「見積もり依頼には、社内の価格表テンプレートに沿って回答する」ルールを設定
- 業界特有の用語集や FAQ をスキルとして登録

### 5. ウェブ検索統合

ナレッジベースの情報に加え、リアルタイムのウェブ情報も AI が自動で取得・統合。社内知識と最新情報を組み合わせた回答を提供します。

**特長:**
- **自動判断**: KB 検索で不足がある場合、AI が自動的にウェブ検索を実行
- **多角的調査**: 1 回の検索で終わらず、複数のキーワード・角度から調査を継続
- **出典明記**: KB 出典とウェブ出典を明確に区別して記載
- **全文取得**: 検索結果のサマリーだけでなく、重要なページの全文を取得して精度を向上

## Salesforce 連携の詳細アーキテクチャ

```
Salesforce Sales Cloud
        │
        │  REST API / Bulk API（定期自動同期）
        │
        ▼
┌─────────────────────────┐
│  Salesforce Connector   │
│  ┌───────────────────┐  │
│  │ データマッピング   │  │    同期対象オブジェクト:
│  │ & 変換             │  │    ・Account（取引先）
│  └────────┬──────────┘  │    ・Opportunity（商談）
│           │              │    ・Lead（リード）
│           ▼              │    ・Contact（担当者）
│  ┌───────────────────┐  │    ・Activity（活動履歴）
│  │ KB 自動登録       │  │    ・Task / Event
│  └────────┬──────────┘  │
└───────────┼──────────────┘
            │
            ▼
    ナレッジベース (RAG)
    ┌───────────────────┐
    │ Knowledge Graph   │  ← 顧客間の関係性も自動マッピング
    │ + Vector Store    │  ← 意味検索で自然言語クエリ対応
    └───────────────────┘
            │
            ▼
    AI チャット → 営業担当に自然言語で回答
```

### データ同期フロー

1. **初回同期**: Salesforce OAuth 認証後、対象オブジェクトを一括取得
2. **差分同期**: 定期的（設定可能）に更新データのみ差分同期
3. **KB 自動更新**: 取得データをナレッジベースに自動登録 → Knowledge Graph を更新
4. **即時利用**: 同期完了後、AI チャットで即座にクエリ可能

| 項目 | 効果 |
|---|---|

### 経営・技術責任者にとって

- **低コスト導入**: GPU 不要、Docker Compose でワンコマンドデプロイ
- **セキュリティ**: オンプレミス / プライベートクラウドに完全対応。データは社内に留まる
- **拡張性**: スキルシステムで業務特化のカスタマイズが可能
- **既存資産活用**: Salesforce のデータをそのまま AI に活用、二重管理不要
- **軽量運用**: 全コンテナ合計 約 410 MB、専任管理者不要

## セキュリティとデータ管理

| 項目 | 対応 |
|---|---|
| データ保存 | オンプレミス / プライベートクラウド対応。データは社外に出ない |
